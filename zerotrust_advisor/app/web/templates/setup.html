Router-side setup (UniFi UDM Pro example)

Router firmware and menu layout drift over time — treat this as a starting point, not gospel.

  1. Firewall logging. On the rules you want visibility into (especially inter-VLAN rules), enable per-rule logging and point syslog at this add-on's host on UDP port {{ config.syslog_port }}.
  2. NetFlow/IPFIX export. Settings → CyberSecure → Traffic Logging → enable NetFlow, pointed at UDP port {{ config.netflow_port }}. Note: on hardware that offloads inter-VLAN routing, this will only ever show WAN-crossing traffic — see the warning above if that applies to you.
  3. Set Allowed source IPs in Settings to your router's IP, or messages will be received but rejected (see the counts above).
